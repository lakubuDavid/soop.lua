# Dashboard Template Wiki

This wiki defines the design language, architecture, toolchain, database strategy, and testing conventions for the domain-neutral Go + HTMX dashboard template.

The hotel reservation application is the primary reference implementation for proven patterns, but this template is intentionally suitable for SaaS products, internal tools, blogs, tourism guides, CMS applications, marketplaces, and other platforms.
